# 716QX Lounge OS 3.5 [Apex Edition]

نظام تشغيل وإدارة صالات الألعاب والمقاهي المتطور (POS & Lounge Management System). تم بناء المنظومة بهندسة معمارية فائقة الكفاءة تجمع بين تصميم Cyberpunk Glassmorphism، محرك فضاء تفاعلي ثلاثي الأبعاد، حماية أمنية مشددة ضد التلاعب البرمجي، واستقرار بنسبة 100% أثناء انقطاع الإنترنت.

---

## 🏗️ البنية المعمارية للملفات (Project Structure)

```text
716qx-lounge-os/
├── index.html           # واجهة المستخدم الهيكلية ونقاط ارتكاز الشاشات والنوافذ المنبثقة
├── styles.css           # نظام التصميم Glassmorphism، متغيرات CSS، وحركات النيون
├── 3d-space.js          # محرك الكانفاس ثلاثي الأبعاد المقفل على 60 إطاراً في الثانية
├── security.js          # درع الحماية، فلترة وتطهير المدخلات (XSS)، ومكافحة التفتيش
├── app.js               # المحرك المحاسبي، العدادات الذكية، وإدارة الجلسات والديون
├── sw.js                # عامل الخدمة (Service Worker) للتشغيل الذاتي دون إنترنت
├── manifest.json        # تعريف تطبيق الويب التقدمي (PWA) للتركيب على الأجهزة
├── server.js            # خادم شبكة محلية (LAN) مبني بدون أي حزم خارجية (Zero-Dependency)
├── electron-main.js     # مشغل سطح المكتب المستقل مع وضع الكشك والشاشات الكاملة
└── package.json         # تعريف أوامر التشغيل وحزم التطوير المساعدة
